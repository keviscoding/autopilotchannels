## Component Breakdown

### 1. Navigation
- Simple header with logo linking to `#/` (home)
- No additional nav links (keeps it focused)

### 2. Hero Section
- **Pill tag**: "Free Training" (green badge)
- **H1**: "How a faceless YouTube channel actually gets built"
- **Subhead**: Calm explanation of what they'll learn

### 3. Replay Player
- **Dark frame**: Matches brand, premium feel
- **16:9 aspect ratio**: Standard video player size
- **Smart fallback**: Handles WebinarJam iframe blocking
- **Easy URL swap**: Constants at top of file

### 4. Testimonials Section
- **Section title**: "What this looks like when it's working"
- **Proof cards**: 3 image testimonials (Theo, Fahad, Anton)
- **Video testimonials**: 4-7 YouTube clips in grid
- **Disclaimer**: Same honesty language as other pages

### 5. Apply Section
- **Section title**: "Apply for a Channel Install"
- **Bridge copy**: Soft CTA explaining done-for-you option
- **Inline Typeform**: Full embed (not popup)
- **Fine print**: "We read every application..."

### 6. Footer
- Logo, tagline, legal links, disclaimer
- Matches existing site footer exactly

## Design Tokens Used

### Colors
- `--paper`: Warm off-white background (#FAF8F3)
- `--sand`: Alt-section background (#F2EDE4)
- `--green-600`: Primary brand green for CTAs (#15875B)
- `--dark-bg`: Deep evergreen for VSL frame (#11201B)
- `--ink-900`: Text color (#16221F)

### Typography
- `--font-display`: Bricolage Grotesque (headings)
- `--font-sans`: Hanken Grotesk (body)
- Fluid type scales (responsive)

### Components Reused
- `.logo` - Standard site logo
- `.hero` - Hero section pattern
- `.section` - Section spacing
- `.proof-card` - Testimonial cards
- `.ytclip` - YouTube thumbnail → iframe pattern
- `.disclaimer` - Honesty disclaimer box
- `.tf-inline` - Typeform inline embed wrapper
- `.footer` - Site footer

## Attribution Flow

1. **URL params captured**:
   - `?source=video123` → tracked as `source`
   - `?utm_source=youtube&utm_medium=video` → tracked
2. **Defaults applied**:
   - No source? → `source=free_training`
   - `landing_page=/free-training`
3. **Sent to Typeform**:
   - Hidden fields auto-populated
   - Same schema as LandingPage for consistency

## Mobile Responsive

- Hero text scales down gracefully
- Proof cards stack vertically on narrow screens
- Video grid becomes single column < 820px
- Typeform embed adjusts via `inlineOnMobile` prop
- Touch-friendly button sizes maintained
